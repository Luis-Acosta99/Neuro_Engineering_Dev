# Neuroscience Research Group headed by Dra. Luz María Alonso Valerdi 

## Current developments
This repo leans heavily on object oriented programming and concurrent programming paradigms to make signal acquisition paradigms that both present a GUI to the user, and manage to transfer the data from the memory of the acquisition device and onto the computer storage for later analysis. Although not currently implemented, future interests include designing experiments that make realtime use of the sensor streaming data to generate some sort of interaction with the test subject.

At the present time, there are
- An interface for acquiring biosignals from an OPENBCI device
- An interface for acquiring biosignals from a Black Hybrid Unicorn device using their python API (licensed)
- A programmed interface that randomly exposes subject to a sample of questions from a bank previously validated by other authors to investigate spatial ability.
- Initial steps towards an EDA and signal analysis of the data gathered for these experiments.
